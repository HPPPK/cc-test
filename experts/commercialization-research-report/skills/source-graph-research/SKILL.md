# 来源图谱网页调研

## 目标
把“网站 A 提到网站 B”变成可复核的证据链：先保存 A 的来源和链接，再用 Playwright 读取 B；不要把 A 对 B 的转述当作 B 的一手事实。

## 执行
1. 为每个种子 URL 记录 URL、页面标题、页面类型、采集日期、目标字段和来源层级。
2. 从 Playwright 返回的可见链接中筛选与当前章节有关的官网、价格页、应用商店页、官方文档、GitHub、公开社区或公开行业资料。
3. 对每个候选链接 B，使用 Playwright 单独读取；记录 B 是否支持、补充、矛盾或无法验证 A 的说法。
4. 每轮只扩展与当前字段有关的链接，避免无限爬取；没有新证据时停止并记录停止原因。
5. 登录、403/429、robots、地区限制或无关页面必须保留为访问限制，不能用第三方转述替代一手来源。

## 输出
输出来源图谱台账：父来源 | 子来源 URL | 发现方式 | 对应字段 | 支持/矛盾/无关/受限 | 采集日期 | 限制。
对数字、定价、平台、用户规模、市场规模和评价，优先追溯到一手页面或原始发布者。

## 候选 URL 构造与可追溯引用

当只有产品名、竞品名或研究问题时，先从可信来源类别中生成候选入口，而不是直接把模型记忆当事实。候选入口可以是官网根页、官方分发页、公开平台根页、公开站内搜索页、公开话题页、分类页或从已验证页面发现的链接；每个候选入口必须标明查询词、目标字段和来源类型。

1. 用 Playwright 打开每个候选 URL，记录“候选/发现方式、URL、日期、目标字段、可访问/受限/无关/无结果、限制原因”。
2. 从可访问的搜索或列表页中提取真实结果链接；最终若使用某条帖子、视频、评论、报告、商店评价或数据，只能引用 Playwright 进一步打开后的具体内容页。
3. 报告正文、表格或“无结果/访问受限”结论只要依赖某个 URL，该 URL 就必须有来源编号并进入最终信息来源表；未被报告使用的可访问 URL 只留在研究访问台账。
4. 写 HTML 前建立“主张 -> 来源编号 -> 已打开 URL”映射。没有映射的主张要删除、降为待验证假设，或向用户请求材料。
