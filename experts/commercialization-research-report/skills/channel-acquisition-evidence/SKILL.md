# 多源渠道获客证据包

## 目标

为报告第 5.5 节和渠道优先级建议提供真实、可复核的输入：不仅列关键词，还要说明哪些渠道页面、内容、讨论、分发或投放材料实际支持该判断，以及哪些结论目前不能支持。

本 Skill 不预设产品、行业、国家、竞品、平台或渠道。根据本轮产品方向、用户任务、市场范围、已打开页面和用户材料动态选择来源；来源的“广泛”看独立来源类型和实际内容，不看链接数量。

## 工具与边界

- 只用当前会话真实可用的工具。公开页面必须由 `Playwright` 实际打开；只有研究方向缺少 URL 时，可用它的 显式搜索动作 做一次可观察的公开搜索动作序列发现真实链接，再打开具体页面。本 Skill 不授予 Playwright 以外的额外搜索、登录、验证码绕过、批量抓取、付费数据或写文件能力。
- 不能把候选 URL、页面标题、搜索摘要、模型记忆、竞品官网、单个内容页或单一平台热度升级成 SERP 排名、广告投放、用户规模、付费意愿或转化率。
- 页面受限、验证码、403/429、robots、地区限制、登录墙或无关结果都属于有效调研结果：记录限制并继续从其他适用来源类别补充，不要报错或停止报告。

## 研究步骤

### 1. 先构造关键词与验证问题

优先形成 4–6 个有区分度的关键词方向；材料不足时可更少。可按实际产品选择品牌、品类、任务/痛点、替代方案和使用场景，不要求每类都有。

对每个方向写：

`关键词方向 | 希望验证什么 | 需要哪类来源 | 候选入口/查询词 | 当前状态`

### 2. 形成多源候选计划

按本轮真实可获得性选择并尝试以下独立来源类别，而不是机械要求所有类别：

1. **搜索结果或投放快照**：实际可打开的搜索结果页、用户提供 SERP/广告位截图、内部投放后台或合规公开广告资料。
2. **产品与分发页面**：官网、价格页、应用商店、下载站、插件市场、官方文档、官方 GitHub 或更新日志；无论属于本品、竞品还是替代品，均是第一方产品事实，用于产品事实和分发入口，不单独证明需求或来源广泛。
3. **外部内容与社媒**：独立作者、媒体、创作者或用户发布的已打开文章、视频、笔记、公开评论；用于内容供给、品类教育和场景表达线索。单条内容页只说明该页面存在，不能单独证明渠道获客有效、内容规模、用户需求或付费意愿。
4. **公开讨论与评价**：已打开的问答、论坛、评价、功能请求、迁移或替代方案讨论；用于任务、痛点和替代方案信号。
5. **行业、趋势或用户材料**：公开行业资料、权威数据、用户访谈、问卷、客服、投放或内部行为材料；按其原始定义使用。

搜索页、话题页、分类页和平台根页仅用于发现候选链接。若最终引用帖子、视频、评价或文章，必须再打开具体内容页。

### 3. 逐页建立研究回执

每个实际使用的页面都记录：

`来源类别 | 候选入口/发现方式 | 已打开 URL | 页面类型 | 访问日期 | 实际观察/原始表达 | 支持什么 | 不能支持什么 | 状态（已打开/受限/无关/无结果）`

- 只有具备 `已打开 URL + 访问日期 + 实际观察` 的回执，才可使用“本次采集”“已观察”“可见广告位”“排名”“首页”“占据”“未观察到”“未发现”“不存在”等事实态措辞；“未观察到 / 未发现 / 不存在”同样属于负向观察结论，不是可随意使用的证据缺口标签。
- 只有 URL 但未打开时，只能称“候选链接”或“公开页面线索”；未取得对应查询回执时只能写“未取得 / 无法确认”，不能写成未观察到或不存在。
- 只有一个来源类型时，明确写“来源集中”；不要把同一官网、同一平台或多个同类页面算作多源。

### 4. 输出渠道证据包

交给主代理和独立复核子代理的输出必须包含：

1. **关键词地图**：关键词方向、目标用户任务、预期意图、当前证据状态。
2. **来源覆盖摘要**：本轮实际尝试/成功/受限的来源类别；哪些类别是独立外部信号，哪些只是第一方事实。
3. **研究回执台账**：逐条列出实际 URL、日期、观察、限制与证据边界。
4. **5.5 写作映射**：每个表格单元格或渠道建议使用哪些来源编号；应标“已观察、公开页面线索、推断、待验证”中的哪一种。
5. **渠道优先级候选**：核心、辅助、探索渠道各自的依据、适用条件、风险和下一步最低成本验证动作。

## 写入 5.5 的规则

- 先写采集说明，诚实列出本轮取得与缺失的材料；没有真实 SERP/广告位时写“未取得完整 SERP 快照 / SEM 未公开确认”，但继续完成关键词地图与渠道建议。
- SEO 列优先写实际占位来源或来源类型，并在信息来源表保留 URL 和日期；没有完整 SERP 时不得写“排名第一”“全面占位”。
- SEM 列只写真实广告位、用户截图或可复核投放材料；不能用推测的 CPC、广告主数、预算或泛行业常识补全。
- “竞争强度”可以是工作判断，但要标“已观察”或“推断”，说明其来源边界。
- 渠道建议至少区分核心、辅助或探索中的适用层级；每项说明基于何种证据状态、适用条件和验证动作。单条外部内容或只有第一方产品页面时，默认只能作为“探索/待验证”或内容供给线索；只有多个独立信号或真实渠道表现材料才可作为核心渠道的依据。没有预算数据时不编预算比例。

## 完成检查

在返回前自查：

- 是否存在把未打开 URL、单一平台内容、竞品功能页或搜索摘要说成已观察事实？
- 是否把内容供给当成用户需求、市场规模或付费意愿？
- 是否把多条同一官网/同一平台链接当成来源广泛？
- 是否保留了访问受限和无结果，而不是静默用别的来源替代？
- 是否让主代理能在不编造的前提下继续写出完整、可执行的 5.5？
