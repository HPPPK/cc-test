## UIUX generated-image-only applicability
This is the executable image-native adaptation. Audited upstream originals and licenses are archived under third_party and are not runtime instructions.

# UI craft finalize — image acceptance
只检查最后一次成功 image_generation 返回且已 Read 成功的精确图片。
## 十项收口
1. 任务目的是否清晰；2. 确认方向是否体现在信息组织；3. 源图语境与密度是否保留；4. 字体层级与中文断行；5. 对齐与间距；6. 色彩与状态含义；7. 主动作及相邻对象；8. 事实、数量、授权和必保文案；9. 重复/遮挡/乱码；10. 模板感与无功能装饰。
每项仅按真实像素下结论，不执行外部 detector 或声称自动审美评分。使用 taste-redesign、impeccable-visual-refinement、ui-craft-critique、hallmark-anti-slop、source-fidelity-final-pass 的具体结果，不把已注入当成已应用。
## Verdict
统一 generated-image-review-receipt JSON 必须匹配系统给定 schema；标明 imagePath、方法证据、两条独立观察、逐项事实核对、duplicate scan、未解决问题和限制。
有事实不匹配、未知细字或重要视觉缺陷就用 NEEDS_WORK；PASS 仅表示这次自报静态复审，不是业务效果保证。
不强制为无缺陷的图片再做一版。一轮针对性修订后仍有问题就诚实收口，不无限补问或收费重试。
