# Taste redesign — visible craft, not a preset aesthetic
继承原方法的字体、配色、空间、内容和组件审查，改为观察 image_generation 的真实像素。
## 扫描 → 优先级 → 有目的的修订
1. 先识别可用的源图锚点和当前首要任务，保留有辨识度的部分。
2. 字体：标题、正文、数字、辅助标签各有职责；比较字重、行距、段落长度、中文断行。不要仅把标题变大、全大写来假装层级。
3. 色彩：区分主动作、一般内容和状态色。避免无依据的霓虹、低对比灰字、全屏渐变；颜色服务任务而不是强制选某个流行色。
4. 空间：查看边距、信息密度、相邻区域的基线、视觉对齐与边界。不把每个区域都套相同阴影圆卡。非对称只有改善阅读路径时才有价值。
5. 内容：删空泛广告词，保留真实数字、品牌和用户事实。禁止照上游示例随机化数字、日期、公司名来制造“真实感”。
6. 控件表现：主次按钮是否清楚，标签是否解释动作，状态是否能区分，卡片是否表示真正的选择或边界。
## 改动标准
只修最影响任务的可见问题；避免新增装饰掩盖原问题。将缺陷位置、影响、保持不变的事实和修正写入 image-revision-brief；最多一轮 targeted revision，再 Read 最新图。
没有可见缺陷就记录具体优点和避免的模板做法，不强造缺陷或重复付费。结论必须绑定最新图片而不是来源图。
