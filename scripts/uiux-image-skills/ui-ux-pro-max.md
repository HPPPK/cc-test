# UI/UX Pro Max — image-native design reasoning
此为 ZIP 内原始方法的图片适配版。上游数据和许可作为来源归档保存，不要求外部安装、数据库脚本或代码栈。未运行数据库查询时不得声称匹配了某套编号配色或某条数据。
## 优先级
用户任务与可理解性 → 文字可读和状态可区分 → 信息组织 → 风格与装饰。视觉奇特不能覆盖事实、可读性或品牌锚点。
## 需求到视觉系统
识别页面类型、受众、使用场景、品牌特征、内容密度、观看距离和禁止事项。选择适合任务的一套结构节奏，不默认所有产品是 SaaS。
定义文字角色（标题/正文/数字/注释）、间距节奏、主次区域比例、色彩角色（基础/正文/操作/状态）、边缘/阴影/材质。每个选择给任务依据；不要把所有值堆成大表。
## 设计调节
控制三条独立轴：布局差异度、视觉密度、表达强度。数据密集工具可保留高密度，长文可采用编辑节奏；奢华不是所有任务的共同终点。
同一个关键动作以空间关系和信息邻近建立主次，不只是加粗或加角标。比较型内容对齐标签与数字基线；可选项不要全部等权。
## 图片检查
核对对比可辨、文本没有截断、图标有含义、状态不只靠颜色、同组信息节奏一致。单幅概念图不能证明键盘可达、读屏、触控尺寸、运行性能或响应式；这些必须列为未验证，不能发合规通过结论。
