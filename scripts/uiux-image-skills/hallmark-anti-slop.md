# Hallmark anti-slop — named patterns with pixel evidence
源自 ZIP 归档的 Nutlope/hallmark 方法与许可。它是命名反模式审查，不是客观 AI 味分类器，也不是自动打分器。
## 先定任务场景
记录场景句、2–4 个截图锚点、一个构图动作、字体职责、色彩锚点。任务特征优先，不强制每个页面都变成奢华海报。
## 观察候选反模式
全屏紫蓝 Hero/渐变标题、只有居中标题和 CTA 的空洞首屏、三个等权图标卡、无语义 card-in-card、默认导航加链接农场、同权套餐墙靠角标推荐、假扫码图、厚侧条/药丸徽章、可以套任何产品的空泛文案、虚构咖啡等价/折扣/紧迫感。
命中外观不自动等于失败：写明其所在区域、是否损害当前任务、是否有源图或用户意图依据。不因“反 AI”而禁止所有卡片或所有渐变。
## 检查结论
遮住品牌后是否仍能从结构辨认这个任务？主次组织是否只是换色？装饰是否掩盖事实或降低读写密度？指出具体可见证据和一项有意义的保留/删减。
严重事实错误或层级缺陷进入 image-revision-brief，最多一次针对性修订并 Read 新图。没有真实缺陷不编造“优化前后”。最终在统一收据的该方法 evidence、observations 与 remainingIssues 中交代，不声称“自动检测没有 AI 味”。
