# Interface copy craft
适用任何晦涩、生硬或泛化的界面文字：设置、功能说明、内容、上手引导、空状态、错误、成功、购买。价格换算只是一个可选例子，不是默认任务。
## 先拆含义，再重写
1. 提取原句的主体、动作、对象、条件、范围、限制和结果。先写准确的白话释义，未知术语不猜。
2. 划分不可改变的事实和可改表达：数字、单位、周期、权益、限制、政策必须保真；句式、顺序、语气、具体场景可改变。
3. 给出字面清晰版、具体场景版、克制的有趣版。每版说明保留含义、可能误解和长度适配。最终选适合位置的一版，不全塞进界面。
## 创意方法
- 抽象功能 → 可感知动作或结果，例如“启用后台持久化”可写为“关掉窗口，任务仍继续”，但仅在产品确实如此时使用。
- 抽象名词 → 用户动作；被动长句 → 主体明确的短句；术语 → 简短解释加原术语，专业精度不能丢。
- 复杂条件 → 条件在前、结果在后。错误文案说明发生了什么、已保存什么、下一步可做什么；没有事实依据就不承诺自动恢复。
- 轻量比喻/同义转译用于帮助理解，旁边保留必要字面含义。危险操作、费用、授权、错误原因优先直白。
- 价格与日常物品等价必须有可核对的数值、范围、假设和用户接受的语境。不能编造咖啡、电影的价格，也不能用类比隐藏总价或付款周期。
## 反向验收
把新句再译回字面含义，逐项与原事实对照；是否新增“无限”“免费”“安全”“家庭共享”等承诺？是否让用户猜按钮含义？是否换到任何产品都成立？是否只是堆营销形容词？
如不确定，使用准确的字面回退，不为有趣而改事实。在生图简报中提供最终精确文案，终图复审检查文字是否被生成模型篡改。
