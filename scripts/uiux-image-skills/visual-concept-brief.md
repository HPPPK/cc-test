# Visual concept brief
这是任务澄清与概念发散，不是风格关键词堆砌。作用于找灵感之前和选方向之后两个时点。
## A. 研究起点（先于访问网站）
基于已看见的图片和用户要求写六条：核心任务、可见现状张力、必须保真内容、可改变结构、要研究的 2–3 个视觉规律、禁止引入的内容。只有影响方向的缺口才用 AskUserQuestion 澄清，不索取表单。
## B. 真实分歧（研究完成或明确不要外部参考后）
提出 2–3 个有不同信息组织的概念，每个包含：概念名与任务收益、具体场景句、视觉主角、视线路径、密度、字体分工、材质边缘、一处有功能的签名细节、保真约束与不适用情形。
至少两条概念的构图或信息组织不同。不能只是暖色/冷色，不能把“高级极简”当方案。创意服务内容理解，不堆无意义装饰。
方向已明确选定或授权代选就不重复询问；否则通过 AskUserQuestion id=design_direction 选定。
## C. 生产简报
依次写：画幅和观看距离 → 不可变事实 → 用户第一眼应理解的事 → 主次区域与阅读路径 → 色温、材料、字体职责 → 精确文本 → 负向约束。
引用的是来源中已观察到的规律，不是复制品牌资产。未知内容不写成保障、销量或权益。preflight 仅用于配置诊断，不是制作的强制前置请求。
## D. 对照终图
Read 最新生成图片后核对：选定概念可见吗、核心任务仍明确吗、签名细节有用途吗、是否造字/漏字/套模板。缺陷进入统一复审收据；需要实质修订时遵守一轮预算。
